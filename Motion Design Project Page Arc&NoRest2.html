PROJECT OVERVIEW

The Project

A concise overview of the project's creative direction, my contribution and the final deliverable.

Project Overview

This project explores how typography, graphic elements and animation can work together to create a cohesive visual piece.

The focus was on creating purposeful motion that supports the visual direction while maintaining clarity, rhythm and consistency throughout the final animation.

PROJECT TYPE Motion Graphics / Animation
MY ROLE Motion Designer / Editor
